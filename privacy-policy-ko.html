기기 내 정보

앱 이름·패키지명·유형, OS 이용 시간과 실행·화면 이벤트 시각을 대상 선택·통계·제안·한도 판정에 사용합니다. 접근성은 선택한 대상을 찾기 위해 현재 앱·주소 표시줄·조작 버튼을 처리합니다. 다른 앱의 본문·입력, 화면 이미지, 전체 방문 URL과 검색어는 저장·전송하지 않습니다. 지정 도메인과 한도 카운터는 기기에 저장합니다.

선택 분석과 보조 기능

상세 웹·숏폼 분석은 선택 기능으로 확인 가능한 도메인·유형·시간을 기록합니다. 웹 분석에는 확인된 일반 탭만 사용하며 비공개·알 수 없는 탭은 제외합니다. 선택한 한도 카운터는 별도로 처리합니다. 알림·음성 보조 기능은 발신 앱과 미디어 조작 정보를 사용하지만 알림 본문이나 재생 내용은 저장·전송하지 않습니다.

통신과 내보내기

Play 버전에는 INTERNET 권한이 없으며 이용 기록·규칙·비밀번호를 개발자나 제3자에게 자동 전송하지 않습니다. 설정은 사용자가 선택한 위치에 내보내며 클라우드 저장소는 자체 방침을 확인해야 합니다. 정책 링크는 외부 브라우저로, 문의는 이메일 앱으로 열립니다. 자동 전송·첨부는 없습니다.

보관과 삭제

분석은 최대 90일, 상세 구간은 약 3일 후 정리합니다. 규칙·설정·분류·동의·비밀번호 검증값은 삭제할 때까지, 실행 중 한도 카운터는 종료까지 유지합니다. 비밀번호 자체는 저장·내보내지 않습니다. 설정→기록 관리에서 분석을 중지·삭제하세요. Android 설정의 데이터 삭제·앱 제거로 전체 기록을 삭제할 수 있습니다. OS 이용 기록과 내보낸 파일은 별도로 관리합니다.

선택과 권한

이용 기록과 접근성은 각각 목적 안내, 명시적인 동의, OS 허용 후 사용합니다. 보조 권한은 선택한 기능에만 필요합니다. OS 권한 해제·데이터 삭제·앱 제거는 유지됩니다. 규칙은 직접 채택·시작하며 적응 플랜은 승인한 범위 안에서 향후 한도만 조정합니다.
